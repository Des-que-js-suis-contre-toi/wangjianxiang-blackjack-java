# 21 点（Blackjack）· Java 控制台版

玩家对战庄家的控制台 21 点游戏，支持连续多局、战绩统计与完整的输入校验。

## 一、运行环境

- JDK 17 及以上（开发与测试环境：Temurin 21）
- Windows / macOS / Linux 均可，无第三方依赖

## 二、目录结构

```
blackjack/
├─ src/blackjack/
│  ├─ BlackjackGame.java   程序入口：游戏流程、交互、结算
│  ├─ Player.java          手牌管理与点数计算
│  ├─ Deck.java            一副 52 张牌：洗牌、发牌、回收
│  └─ Card.java            花色与点数枚举
├─ run.bat                 Windows 一键编译并运行
├─ .gitignore
└─ README.md
```



## 三、玩法说明

| 输入 | 含义 |
| --- | --- |
| `H` | 要牌 |
| `S` | 停牌 |
| `Q` | 退出本局并结束游戏 |
| `Y` / `N` | 一局结束后：再来一局 / 结束 |

规则：

1. 一副 52 张牌，每局重新洗牌。
2. A 记 1 或 11（取不超过 21 点的最大值），J/Q/K 记 10 点。
3. 双方各发两张，庄家的第二张是暗牌。
4. 玩家超过 21 点立即爆牌判负，庄家不再要牌。
5. 玩家停牌后庄家翻开暗牌，**不足 17 点必须继续要牌**，达到 17 点即停（软 17 也停）。
6. 双方都没爆牌时比点数，大者获胜，相同为平局。
7. 起手两张即 21 点为 **Blackjack**，直接结算（双方都是则平局）。
